# Fondos de plataformas

Colocá aquí, cuando estén disponibles y con autorización de uso, los siguientes archivos WebP:

- ps2.webp
- ps3.webp
- ps4.webp
- ps5.webp
- switch.webp

Las tarjetas ya aplican overlay y degradado automáticamente. Las imágenes se usan como fondo y se recomienda una composición que mantenga la consola lejos del sector inferior izquierdo, donde se muestra el texto.

Si un archivo no existe, GAMEZONE 777 mantiene el fallback CSS premium; no se muestra una imagen rota.
