# Video del hero

Para activar el video de fondo del inicio, colocá en esta carpeta:

gamezone-hero.mp4

El video se reproduce automáticamente, sin sonido, en loop y sin controles. El hero incluye overlay oscuro y degradado para conservar la legibilidad. Si el archivo no existe, no carga o la persona prefiere reducir movimiento, se muestra el fallback visual CSS.
